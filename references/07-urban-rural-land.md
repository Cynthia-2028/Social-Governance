# 城乡关系与土地制度

本文件处理城乡二元结构的制度根源、土地制度与增长模式、土地财政的闭环及其转折。依据等级：〔A〕多来源经验材料支撑；〔B〕单一来源经验或制度文本支撑；〔C〕概念推演，尚缺直接证据。涉及改革方向的内容一律标注为学界讨论中的主张，不作为本知识库的结论。

---

## 一、城市化的一般机制

城市由密度定义。经济聚集度高于人口聚集度时，人口继续流入；两者持平时聚集到边界。这是分析所有城乡制度的基准：任何制度安排都可追问一句，它阻断还是促进了两者的互相强化。中国长期呈现工业化超前、城市化滞后：城市化率与工业化率之比低于世界均值。〔B〕

## 二、城乡二元结构的制度根源

五项安排及其作用方式：

| 安排 | 起作用的方式 |
|---|---|
| 迁移审批 | 二十世纪五十年代前期连发文件，对农民进城由劝转止 |
| 宪法条款 | 一九五四年宪法曾写入居住和迁徙自由，随后连发文件限制进城；该自由此后未再入宪 |
| 户口登记 | 一九五八年条例规定农村迁往城市须持录用、录取或准迁证明 |
| 统购统销 | 禁止农民转向高收益用途，压低农产品征集的机会成本 |
| 人民公社 | 政社合一，成员身份随出生取得，出口被封 |

**关键机制是两项安排互补**：单方向动用强制力效果有限，因为农民会流向收入更高的部门；一旦流动被禁止，低价征购才可持续。这解释了为何禁止流动与低价征购同时出现而非先后替代。〔B〕

结果可量化：城镇化率在一段时间内不升反降；城乡差别由阶级差别转为等级差别，判据是身份变换的难度高于职业变换。〔B〕

**松动的机制。** 一九八四年中央文件一句允许农民自理口粮到集镇落户，把已发生的行为转为合法。政策文本的力量在于用同一形式的文件解除前一形式的文件。此后人口城市化先于土地城市化启动。〔B〕

**权利发育的不平衡**是理解土地城市化快于人口城市化的钥匙：农民进城居住的权利发育偏慢（户籍、子女教育、社保可携带性制约安家落户），农地转为城市之用的权利发育偏快（征地通道畅通）。两项权利发育速度之差，直接产出统计事实。〔B〕

## 三、土地转用的制度链条

**法律序列**（这一段只依赖法条，是全部讨论中最硬的部分）：

1. 一九八二年宪法：城市土地属于国家所有；征地须为公共利益并给予补偿。
2. 一九八七年深圳首次公开拍卖土地使用权，土地首次作为资产进入市场。
3. 一九八八年宪法修正案：土地的使用权可以依照法律的规定转让，未限定国有或集体。
4. 一九九〇年国务院条例只出台城镇国有土地出让转让办法，集体土地办法未出。
5. 一九九八年土地管理法确立用途管制，并规定集体土地使用权不得出让、转让、出租用于非农建设。

宪法文本给的是无限定表述，下位法把范围收窄为仅国有土地可流转。土地转用的合法通道由此压缩为征地一条，非公益用地也只能经由征收取得。〔B〕

**三重管制**叠加作用于农地转用：城市规划（硬约束）、土地用途管制（城界外扩条件下趋软）、所有制管制（农地转用必须变性为国有）。第四重是年度计划指标与审批，指标自上而下下达，与地方需求脱节，出现指标年年不够用、年年用不完。〔B〕

**补偿制度。** 征地补偿长期按原用途年产值倍数计算，法定上限而无下限。公共利益原则长期未被界定，征地范围随立法演进而放宽。农民按农业用途获得补偿，不能分享转用后的增值收益；征地补偿占出让收入的比重随城市地价上涨而下降。〔B〕

**双轨供地。** 工业用地低价甚至倒贴出让以招商引资，经营性用地限量招拍挂高价出让以获取收入，同一稀缺要素出现两种价格。价格分化的机制：制造业投资可跨区流动，地方只能以低价争抢；服务业须在本地提供，地方在商住用地上有谈判能力。工业用地与商住用地的价格比随年份显著扩大。〔B〕

## 四、土地财政的闭环

六步因果链：

1. **触发条件**：分税制后地方可支配财力份额下降而支出责任未减；住房货币化启动；经营性用地招拍挂确立。
2. **征地**：地方政府是唯一征地主体，补偿按农业产值倍数计算；补偿基准与出让基准的差额构成土地收入来源，也是征地纠纷的结构性起点。
3. **一级开发与出让**：储备中心与政府性公司负责生地转熟地；净收益约占出让总额一至三成，高度依赖商住用地价格。
4. **财政端放大**：土地收入分直接税收、间接税收、部门收费、出让金净收益四块，仅核算出让金会严重低估土地对财政的贡献。
5. **金融端放大**：以土地抵押为主获取贷款；抵押价值以地价为锚，地价以房价为锚，房价以居民收入为锚，链条末端是居民收入。
6. **再循环**：城市建设产生新用地需求，推动新一轮征地。

**三个特征**：不以工业化为前提；不以人口城市化为必要条件（土地城市化可以只靠土地、财政、金融三要素运转）；在短期内最易操作、政绩最显著。〔A〕

**风险堆积点**：地方政府同时是征地垄断者、土地供应者与信贷担保人，地价下跌会同时冲击财政收入、平台偿付能力与银行资产质量。土地资本化的实质是居民收入的资本化，以土地为中心的城镇化在收入增长放缓时会自我约束。〔A〕

**约束条件下的变形**：用地指标收紧后，出现宅基地复垦换建设用地指标并跨区域流转的安排，指标价格与安置成本构成新的动力与风险点。〔B〕

## 五、以地谋发展的模式及其转折

增长链条有四条：土地宽供应拉增长；低价工业用地推动工业化；土地资本化推动城市化；土地财政闭环支撑建设。经济高速增长期四条互相强化；经济换挡后依次失效：宽供应拉不动增长、低价招商效力减退、供地结构扭曲加剧、抵押融资风险累积。〔A〕

转折的量化标志：工业用地与房地产用地占比下降、基础设施类用地占比上升；征地拆迁等成本性支出占出让收入比重过半，政府实际可支配的土地净收益占比降至两成上下；土地抵押贷款规模庞大。可持续性问题不在收入总量，而在净收益占比下降与成本性支出刚性上升的相反走势。〔A〕

**集体建设用地的通道变化**：改革初期农村土地转集体建设用地通道敞开；一九九八年紧缩后合法入市通道基本关闭，乡村非农经济活动萎缩，农民在乡村的发展机会受阻，加快离土出村。此后政策重新开口，集体经营性建设用地获准与国有土地同等入市、同权同价；现实困境是大量法外状态、缺抵押融资功能、未纳入城乡规划、集体组织治理结构滞后。〔B〕

**宅基地制度**：集体所有、农户长期使用、房屋私有；物权层面只赋占有与使用权，缺收益权。内在张力有三：法律禁止流转而事实上大量入市；无偿取得与一户一宅在人地紧张地区名存实亡；无偿分配占用承包地。成员身份性与社区封闭使村内成员不放弃、村外成员进不来，加剧村庄分化。〔B〕

**承包地制度**：成员权集体所有制内含人人有份，增人应调地；增人不增地、减人不减地与承包关系长久不变把人地固定对应，成员权观念与产权排他性由此冲突。承包期内可调地的规则使每户承包地附带无法估值的未来义务，构成土地转让与抵押的交易费用来源。〔B〕

## 六、增长模式的结构解释

一类解释把增长模式拆为三块：制造业下游的市场化竞争；两层逐底式竞争（国际层面以汇率与出口退税，国内层面地方以地价、劳工、环保竞争）；上游能源原材料、金融、城市商住用地三领域的行政性垄断。土地财政与土地金融是这套组合的融资端而非原因端。此说与单纯归因财政的说法构成竞争，检验方法是把财力比例与实际行为分开看：分税制后地方财力占比上升而行为逻辑未变，说明以财力比例判断集权分权会倒果为因。〔B〕

## 七、政策争议的地图

以下列出有分歧的议题，只摆主张与依据，不裁断：

1. **征地制度改革深度**：一派主张缩小征地范围、允许集体土地直接入市；另一派强调规划与用途管制优先，担心直接入市冲击耕地保护与城市规划。
2. **土地增值收益归属**：涨价归公的主张认为由规划与公共投资带来的增值应归社会共享；反对者指出操作上难以区分自然增值与投资增值。
3. **指标交易**：支持者认为建设用地指标跨区域交易能提高配置效率；批评者关注指标生成过程中的农民参与权与安置质量。
4. **宅基地有偿退出**：一派主张有偿退出促进市民化；另一派强调退出须以城市稳定居住与社保覆盖为前提，警惕以退出为进城条件的安排。
5. **集体经营性建设用地的入市范围**：全面放开与分步放开之争，焦点在区位管制与规划权归属。

评估任何一方主张，用三个问题：它对耕地与粮食安全的假设是否成立；它对农民风险承受力的假设是否成立；它对地方财政依赖的过渡期是否给了出路。〔C〕

## 八、做研究时的数据与操作

- 财政侧：地方一般公共预算收支、转移支付决算、土地出让收支决算。注意出让收入含成本性支出，须用净收益口径。
- 土地侧：土地供应与出让数据（分用途、分方式）、抵押融资数据。注意协议与招拍挂口径差异。
- 债务侧：融资平台报表、地方债务限额与余额。注意显性与隐性口径、担保与承诺的差异。
- 人口侧：常住人口与户籍人口两个城镇化率的差额是常用代理，但要扣除城中村户籍水分。
- 设计建议：工业与商住用地价格比、出让时序与任期节点、指标价格的空间梯度是三个可操作化的切入点。〔C〕

## 九、这一领域的解释边界

土地与城乡的解释框架对增长期最有效。三类现象需要补充工具：人口流出地区的收缩治理（框架默认人口流入）；生态功能区的价值实现（框架默认开发权为稀缺资源）；跨省人口流动的服务供给（属地财政与人口分布错位）。〔C〕
