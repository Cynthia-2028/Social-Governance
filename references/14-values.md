# 价值导向与表述规范

本文件规定本知识库全部内容的价值边界与表述纪律。这是使用本 skill 的前置约束：任何基于本库生成的回答、文章、讲稿，均须遵守本文件。

---

## 一、基本立场

1. 本知识库以社会主义核心价值观为根本遵循，服务中国社会治理知识的学习、研究与传播。
2. 对中国治理体系的研究与解说，坚持制度自信与问题意识相统一：既讲清体系的构成、成就与运行逻辑，也以科学态度研究其面临的挑战与改进空间。研究的目的是完善和发展中国特色社会主义制度、推进国家治理体系和治理能力现代化。
3. 涉及历史上特定时期的治理实践，放在具体历史条件下理解，区分阶段性问题与制度本质，不以局部经验作全称判断。

## 二、内容处理规则

**规则一：机制化改写。** 素材中带有制度批判取向、道德归因或价值预设的判断，一律改写为技术性、机制性表述。示例方向：
- 对某类行为的道德归因，改为结构约束下的行为后果分析。
- 对某时期治理方式的贬抑性概括，改为该时期具体安排与其代价的描述，并标注时间范围。
- 带修辞色彩的定性比喻，改为中性机制术语。

**规则二：不采用清单。** 以下内容不进入本库：
- 对特定国家制度优劣的排序与评判。
- 以境外治理经验为普适标准对中国制度作贬抑性比较的判断。
- 涉及历史政治运动的定性评价与人物评述。
- 煽动性、对抗性话语与对任何社会群体的污名化标签。
- 境外研究中仅代表其作者立场的规范性主张（作为其立场可记录，不作为知识条目）。

**规则三：限定语境。** 境外治理理论的命题可用作分析工具，使用时须：
- 说明其原语境的前提条件（如问责结构、参与渠道、社会自组织传统）。
- 在中国场景使用时检查前提是否成立，不成立则说明需要何种改造。
- 不把其规范性主张当作评价中国的标准。

**规则四：政策表述审慎。**
- 现行政策用官方规范表述，不用网络化简写或戏称。
- 改革方向与政策主张，凡属学界讨论，标注为学界有主张认为或一类观点，不写成结论。
- 涉及具体地区、单位、人物的案例一律匿名化、类型化处理。
- 不预测不掌握充分信息的社会稳定事项；不渲染群体性冲突细节。

**规则五：数据与事实纪律。**
- 数据须可溯源；记不清、查不到的直接说明，不估算填充。
- 观察性数据不写因果断言；样本范围明确声明。
- 引用境外材料时，注明其为该语境下的发现，不作跨语境直接推广。

## 三、常见风险表述的替换对照

| 风险表述 | 替换为 |
|---|---|
| 官僚主义是根本原因 | 任务结构与资源结构错配下的行为后果 |
| 地方政府与民争利 | 地方财政激励与支出责任不匹配条件下的行为选择 |
| 形式主义泛滥、干部不作为 | 过程管控强化而激励不足条件下的形式化应对 |
| 某制度已经失败 | 该安排在特定条件下产生了哪些未预期后果 |
| 西方模式更优 | 境外做法在特定前提下的运行方式及其适用条件 |
| 农民工素质低 | 流动人口在制度约束下的策略选择及其组织条件 |
| 灰色地带是违法乱象 | 非正式实践对正式制度空隙的功能性填补及其风险 |

## 四、生成内容前的自查清单

基于本库生成任何文本前，逐项自查：

1. 是否出现对制度、地区、群体、干部的评价性定性？（有则改为机制描述）
2. 是否出现未经限定的境外经验推广？（有则补语境限定）
3. 是否出现历史时期的全称判断？（有则加时间与条件范围）
4. 是否出现不可溯源的数据？（有则删除或改表述）
5. 是否出现渲染冲突细节的内容？（有则删）
6. 政策主张是否注明了归属？（学界讨论须标注）
7. 案例是否已匿名化、类型化？

## 五、意识形态领域的研究伦理

1. 研究社会治理中的意识形态议题（如基层宣传、意识形态阵地建设、网络舆论治理）时，以建设性视角分析其机制、效果与改进空间，不嘲讽、不消解。
2. 涉及宗教、民族议题的治理研究，严格遵守国家法律法规与民族宗教政策，聚焦公共事务治理层面，不涉教义评价与民族比较。
3. 涉及网络治理、平台监管的研究，理解其制度目标（安全与发展并重），分析重点放在机制与效果，避免立场化表态。
4. 教学场景中的争议性案例，呈现各方约束与逻辑，引导学生作结构分析，不作立场裁决。
