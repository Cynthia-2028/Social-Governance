# 论文写作：社会治理论文的结构与论证

本文件给出社会治理类论文（中文为主，兼容英文）的结构方案、论证纪律与投稿策略。依据等级：〔A〕有评审共识支撑；〔B〕有范例支撑；〔C〕经验建议。

---

## 一、论文的四种基本型

1. **机制型**：核心贡献是揭示一个此前未被命名或未被拆解的机制。结构：现象与谜题、机制假说、证据与过程追踪、竞争解释排除、边界条件。适合个案与质性研究。
2. **检验型**：核心贡献是对一个既有命题给出新的或更严格的检验。结构：命题与竞争假说、识别设计、结果、稳健性、机制讨论。适合量化研究。
3. **概念型**：核心贡献是提出或改造一个概念工具。结构：既有概念的不足、新概念的界定与构成、操作化示例、与相邻概念的区分。风险最高，须证明概念有用（能重新组织经验材料）。
4. **政策型**：核心贡献是对一项政策的运行给出系统的经验评估。结构：政策内容与目标、实施过程、可测后果、副作用、改进空间。注意与智库报告的区别：学术政策研究必须有理论对话与识别策略。〔C〕

## 二、标题与引言

**标题的两种安全写法**：机制式（X 如何影响 Y：来自 Z 的证据）；设问式（为什么 X，一个基于 Z 的解释）。避免纯概念标题与口号式标题。

**引言的四段律**：
1. 现象：用可核实的事实把读者带到问题面前，不铺陈宏观背景超过三句。
2. 谜题：指出直觉预期与实际结果的落差，这个落差就是贡献的来源。
3. 对话：指认两三个既有解释，说明它们各自解释了什么、留下什么没解释。
4. 方案：一句话说清本文用什么材料与方法回答，并预告结构。

引言里最常见的问题是把背景当问题。检验方法：把引言压缩到四百字，若谜题消失了，说明原来就没有谜题。〔C〕

## 三、理论与文献综述

**综述的功能是摆出竞争解释，不是罗列研究。** 推荐结构：按解释逻辑分组（如激励论、结构论、文化论），每组说明其核心机制、证据类型与解释边界，最后指出本文立场所在及其理由。

**对话的纪律**：
- 指代来源时用有研究提出、一类解释等表述，或规范引用；不在正文对具体研究者作评价性描述。
- 移植概念前先做语境校准：说明该概念原语境的前提，与中国场景的差异，以及本文做了什么调整。这一段写不好是外审最常提的意见。
- 中西概念对举时，比较机制而非比较评价。〔C〕

## 四、方法与证据部分

按任务类型自查：
- 个案研究：选样逻辑、进入方式、匿名化、推论边界四项齐全。
- 量化研究：测量对准概念、识别假设交代、稳健性覆盖测量替代。
- 混合研究：两块证据的分工明确（哪块解决什么问题），不重复堆料。
- 文本分析：编码手册可复核、信度检验、人工标注抽样。

凡推演或单一来源的判断，用推断：或方向可辨一类的限定语；凡缺证据，直接写尚缺直接证据。这比含糊表述更能赢得审稿人信任。〔C〕

## 五、论证的六个纪律

1. **层次一致**：全文的单位（县、乡镇、社区、组织、个人）保持一致；跨层结论须加限定。
2. **机制完整**：因果链每一环都有证据或明确标注为推断；跳环是通病。
3. **竞争解释并行**：至少处理一个最强的替代解释；只驳稻草人是硬伤。
4. **反例自首**：主动呈现与自己结论不符的材料并解释之，可信度反而上升。
5. **概念一致**：同一术语全文一个含义；核心概念首次出现处给出工作定义。
6. **价值与事实分离**：分析部分不含价值判断；涉及政策的主张以学界讨论形式呈现。〔A〕

## 六、常见退稿原因与自救

| 退稿意见 | 实际问题 | 自救动作 |
|---|---|---|
| 贡献不清晰 | 没有说清挑战了谁 | 引言第三段重写，点名竞争解释 |
| 案例的特殊性问题 | 未交代个案为何能推一般 | 补机制外推论证或改为机制假说表述 |
| 测量效度 | 指标与概念脱节 | 补测量逻辑与效度检验 |
| 因果识别不足 | 相关当因果 | 补识别策略或降格为描述性发现 |
| 结构混乱 | 机制与发现交叉叙述 | 按谜题、证据、解释重排 |
| 政策建议空泛 | 与发现脱节 | 建议逐条对应一个发现，并给实施条件 |
| 价值判断过重 | 分析夹带评判 | 全文删除评价性形容词，改为机制描述 |

〔A〕

## 七、中英文写作的差异要点

- 中文：重视论证的层次感，段落中心句前置；标题层级不宜超过三级；政策术语用官方表述并保持一致。
- 英文：直接陈述贡献，第一段即亮谜题；时态纪律（文献用现在时，本文发现用过去时）；避免直译中文政策术语，首次出现给拼音加释义。
- 共同纪律：不用排比堆砌；少用破折号；数字与统计表述前后一致。〔C〕

## 八、引用与学术规范

1. 引用以可核实为唯一标准：只引读过的文献；转引注明转引。
2. 观点与措辞均须溯源；综述中的概括性判断也要有出处。
3. 数据来源注明口径与年份；图表可复算是底线。
4. 一稿多投、重复发表、拆分发表（同一语料多篇互不引用）均属高风险行为，须在投稿策略中显式处理。〔A〕

## 九、写作流程建议

1. 先写机制图或因果链草图，一页纸。
2. 按证据可得性倒排：先确定能拿到什么证据，再决定能回答多大的问题。
3. 初稿顺序：方法、发现、讨论、引言、摘要。引言最后写，摘要最后最后写。
4. 修改轮次中，第一轮只砍（删冗余与离题），第二轮只排（结构与顺序），第三轮只磨（句子与术语）。一轮做一件事。〔C〕
