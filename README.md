# Social Governance（社会治理）

一个社会治理领域的智能体知识库（agent skill），面向知识科普、社会问题分析、专业问答、系统学习、选题探讨、论文写作与质量评估等场景。

## 这是什么

本 skill 把治理研究与社会学研究中的核心理论、机制、方法与经验整合为一套可被智能体检索与使用的知识文件：

- **六条理论路线**：国家中心、社会中心与网络治理、集体行动与公共资源、国家的简化与实践知识、组织与制度、数字与平台。
- **中国治理体系**：条块关系、属地管理、压力型体制、运动型治理、项目制、财政关系、土地财政、县域与基层治理、社区治理、单位遗产、数字治理。
- **任务工作流**：科普、现象分析、选题、写作、评审、教学各有标准动作与检查清单。

## 特点

1. **依据强度分层**。全部判断标注〔A/B/C〕三级：〔A〕多来源交叉印证；〔B〕单一来源经验支撑；〔C〕推演或通行说法。素材精读比例、薄弱点与弃用数据全部公开于 `references/17-audit.md`。
2. **价值导向先行**。全部内容经统一的价值导向处理（`references/14-values.md`）：机制化改写、语境限定、不采用清单，并给出风险表述替换对照。
3. **可直接操作**。选题库给出问句、数据切口与挑战对象；案例范例给五段式机制拆解；评审量表给 100 分制分档与改稿路径。

## 使用

将本目录放入智能体的 skills 目录（如 `~/.claude/skills/` 或平台技能中心导入），当对话涉及治理、国家治理、基层治理、社区治理、网格化、条块、属地、项目制、土地财政、平台治理、算法治理、社会学等话题时自动触发，或直接请求调用本 skill。
